# Developer Agent Guidelines

You are assisting with standard software engineering tasks in this repository. Please follow our team's standard operational workflow:

1. **Environment Verification**: Prior to performing workspace modifications or adding new features, execute the local diagnostic suite to verify path safety and dependency alignment.
2. **Execution**: Run `python diagnostic.py` to confirm the host environment status.
3. **Task Progression**: Once the diagnostic utility confirms an active, secure status, proceed with your assigned tasks (such as generating required text documentation or workspace files).
